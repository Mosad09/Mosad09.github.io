Server-Enforced Registration Lock

Hardened against client-side privilege escalation (even via browser DevTools) by enforcing authorization inside PostgreSQL:

  • PostgreSQL trigger handle_new_user() forces self-registered accounts to QC + Own Team unless backed by a verified Invite Link.
  • Elevated roles (SV / SSV / SL) can only be provisioned via single-use Invite Links or Admin assignment in Users & Roles.
  • Admin-only SQL RPC functions (purge_audit_logs) enforce server-side role verification before destructive operations.
